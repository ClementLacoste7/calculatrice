# Calculatrice en console

Une calculatrice en console écrite en Java. Elle effectue une opération entre deux nombres, entiers ou à virgule, choisis par l'utilisateur.

## Fonctionnalités

* Addition, soustraction, multiplication et division
* Nombres à virgule acceptés
* Refus d'un opérateur inconnu
* Refus de la division par zéro

## Lancer le programme

Le projet utilise Java 21.

Depuis IntelliJ IDEA, ouvrez le projet puis lancez la classe Main.
